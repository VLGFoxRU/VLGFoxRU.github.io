## 🔧 **API и интеграции**

### 📊 **GitHub API**

```javascript
// Загрузка последних 12 репозиториев
const REPOS_URL = `https://api.github.com/users/VLGFoxRU/repos?sort=updated&per_page=12`;

fetch(REPOS_URL)
  .then(response => response.json())
  .then(repos => {
    // Фильтр: не форки
    repos.filter(repo => !repo.fork)
    // Вывод: карточка для каждого
  })
```

**Отображаемые данные:**
- `repo.name` — название проекта
- `repo.description` — описание
- `repo.language` — язык программирования
- `repo.stargazers_count` — количество звёзд
- `repo.html_url` — ссылка на GitHub
